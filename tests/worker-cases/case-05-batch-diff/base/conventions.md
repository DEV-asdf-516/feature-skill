# 프로젝트 컨벤션

## 계층 책임
1. 컨트롤러는 파라미터 바인딩과 서비스 호출·결과 반환만 한다. 판단·계산·변환은 서비스가 한다.
2. 응답 DTO 는 값을 담기만 한다. 도메인 엔티티나 유틸을 참조·호출하지 않는다.

## 책임 배치 (Tell, Don't Ask)
3. 여러 필드의 상태를 꺼내 비교·판단하는 코드를 호출자에 두지 않는다. 비교·판단·조립은 그 데이터를 소유한 객체나 지정된 유틸에 맡긴다. 변경 감지·이력 기록처럼 여러 필드에 같은 처리를 하는 작업은 필드별 조건문 나열이 아니라 필드 `Map` 기반 일괄 처리(`DiffUtil` 등)로 한다.

## 명명
4. 조회 메서드는 `find`/`get` 접두사를 쓰고, 없으면 예외를 던지는 조회는 `findOrThrow` 형태를 쓴다.
