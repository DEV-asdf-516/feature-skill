[CORE RULES — 매 턴 강제 적용. 아래 전 항목은 협상 불가]
- CAUTION: 명시적 지시 전 코드 수정 금지. 명시적 지시 전 커밋/푸시 금지. (모든 작업별 적용)
- 구현 전: 가정 명시. 불확실하면 질문. 복수 해석 시 옵션 제시(묵시적 선택 금지). 더 단순한 방법이 있으면 먼저 언급.
- Surgical: 요청 범위만 수정. 인접 코드/주석/포맷 임의 개선 금지. 기존 스타일 준수. 기존 dead code는 언급만, 삭제 금지. 내 변경이 만든 orphan만 제거.
- 변수명: tmp/temp/data/단일 문자(루프 인덱스 i, j 제외) 금지. 의미가 드러나는 이름만 사용.
- 연관 파라미터 3개 이상은 객체로 묶고, 호출 체인 끝까지 객체 그대로 전달(중간 해체 금지).
- **새 로직 작성 전 기존 유틸 탐색 후 재사용.** 
- 존댓말. 결론 먼저. 검증된 사실과 의견 구분.
